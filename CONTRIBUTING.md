How to contribute

    Fork the repository.
    Create a feature branch.
    Commit changes with clear messages.
    Open a pull request describing your changes and listing files affected.

Required Contributor statement

Add the following short statement in your pull request description or a CONTRIBUTORS file entry:
"I hereby license my contributions to this repository under the Creative Commons Attribution 4.0 International (CC BY 4.0) license."
Code of Conduct

Be respectful. Report violations by opening an issue labeled "conduct".
Submitting larger contributions or corporate contributions

If you represent a company or are submitting a substantial amount of content, consider including a short signed statement from an authorized representative that the contributor has the right to license the content under CC BY 4.0.
